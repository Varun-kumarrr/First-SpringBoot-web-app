## ▶️ Running the Project

### Clone the repository

```bash
git clone https://github.com/Varun-kumarrr/First-SpringBoot-web-app.git
```

### Navigate to the project

```bash
cd First-SpringBoot-web-app
```

### Run the application

```bash
./mvnw spring-boot:run
```

or on Windows

```bash
mvnw.cmd spring-boot:run
```

The application starts on:

```
http://localhost:8080
```
